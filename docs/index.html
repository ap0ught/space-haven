Space Haven Mods

A small collection of Space Haven mods by Killparadise, plus a developer template for building Java-based mods, with links back to source files and published releases.

View repository Read provenance notes

Where these came from

Four mods in this repository were published on Nexus Mods. Two more are preserved here as repository-only work: Hyperdrive Mass Config, which was never released, and Zero System Points, which is marked deprecated in its own metadata.

Developer resources

The repository now also carries the upstream SpaceHavenModTemplate from the Spacehaven modding tools developers under its original MIT license. It provides a Maven + AspectJ starter project for runtime patch mods.

Improved Airlock

Published

Boosts airlock oxygen capacity, suit locker oxygen, and docking inventory limits.

  • Airlock oxygen: 6,000 → 10,000
  • Outgoing / incoming inventory: 10 → 20
  • Suit locker oxygen: 6,000 → 7,000
  • Airlock doorway oxygen: 1,000 → 3,500

Configurable through five loader variables in info.xml.

Source Nexus Mods

Improved Shuttles

Published

Upgrades shuttle and miner capacity so small craft stay useful longer.

  • Shuttle crew: 4 → 5
  • Shuttle oxygen: 10,000 → 16,500
  • Shuttle carry capacity: 10 → 20
  • Miner oxygen: 4,000 → 7,000
  • Miner ore capacity: 5 → 10

Configurable through five loader variables in info.xml.

Source Nexus Mods

Pack Wagon

Published

Turns storage-heavy ships into cargo haulers by increasing storage capacities.

  • Large storage: 250 → 550
  • Small storage: 50 → 150
  • Body storage: 20 → 50
  • Robot storage: 20 → 50

Configurable through four loader variables in info.xml.

Source Nexus Mods

Less System Points

Published

Reduces system point requirements for generators, hyperdrives, defenses, and craft.

  • Config covers 17 different structures and ships
  • Defaults make most entries cost 0 or 1 system point
  • Hull stabilizer and fighters keep slightly higher defaults

This is the configurable successor to Zero System Points.

Source Nexus Mods

Hyperdrive Mass Config

Repository-only

Raises hyperdrive mass capacity and keeps both drive tiers configurable.

  • X1 hyperdrive mass capacity: 3,200
  • Hyperium hyperdrive mass capacity: 1,800

The repository README previously noted this one was not released to Nexus Mods.

Source

Zero System Points

Deprecated

An older, non-configurable version of the system point tweaks kept for reference.

  • Sets hull stabilizer, shield, scanner, jammer, and turrets to 0
  • Superseded by Less System Points

Marked as deprecated directly in info.xml.
